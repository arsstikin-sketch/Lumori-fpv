# FPV Drone для Minecraft 26.3

Мод Fabric добавляет полёт FPV-дрона с пультом или клавиатурой. Плагин Paper показывает дрон, птицу или ванильного моба другим игрокам. Игрокам без мода ничего устанавливать не нужно.

| Папка | Содержимое |
|---|---|
| `mod/` | клиентский мод и серверная часть для Fabric |
| `plugin/` | плагин для Paper |
| `docs/` | исторические заметки и описание моделей |

## Установка и сборка

Нужен Minecraft 26.3 и JDK 25. Пилоту нужны Fabric Loader 0.19.5, Fabric API 0.165.2+26.3 и собранный мод в `mods/`. На Paper-сервер положите собранный плагин в `plugins/`. На Fabric-сервере можно установить серверную часть мода. Старые JAR перед обновлением замените; две версии одновременно оставлять нельзя.

```text
cd mod     && gradlew.bat build
cd plugin  && gradlew.bat build
```

JAR появятся в `mod/build/libs/` и `plugin/build/libs/`. На Linux/macOS используйте `./gradlew build`.

## Управление

`R` — арм/дизарм, `V` — переключить вид, `Backspace` — убрать дрон, `H` — новый дрон, `K` — настроить пульт, `O` — настройки, `M` — Acro/Level. На вкладке «Управление» доступны три схемы:

- **FPV: A/D рыскание:** W/S — газ; A/D — рыскание; вертикаль мыши — тангаж, горизонталь — крен.
- **Клавиатура: поворот A/D:** Space/Shift — газ; W/S — тангаж; A/D — рыскание с автоматическим креном.
- **Свободный полёт:** камера задаёт направление, WASD перемещает дрон относительно взгляда, Space/Shift меняют высоту.

Вкладка управления показывает схему клавиш и мыши. Вкладка «Пульт» показывает положение откалиброванных стиков подключённого контроллера. При максимальной прочности `∞` дрон не повреждается и не уничтожается водой или лавой.

## Серверные настройки

В `plugins/FpvDrone/config.yml` параметр `max-range: 0` разрешает игроку выбрать дальность от 8 до 512 блоков; положительное число фиксирует её. В разделе `damage` значения `durability`, `safe-contact`, `propeller-break`, `motor-break`, `frame-destroy` равны 0 для выбора игроком или положительному числу для фиксированного значения. `damage.liquids-destroy` принимает `client`, `true`, `false`. Фиксированный сервером ползунок или переключатель в моде показывает действующее значение и блокируется. `stabilization.allowed` принимает `All`, `Acro`, `Level`. Изменения конфигурации применяются через `/drone reload`.

`/flyskin` открывает выбор птиц и мобов; `/flyskin admin` открывает панель доступности и размеров скинов; `/flyskin enable <id>` и `/flyskin disable <id>` работают без панели. Подробности — в [документации плагина](plugin/README.md), история изменений — в [CHANGELOG.md](CHANGELOG.md).

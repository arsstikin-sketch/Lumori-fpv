# FpvDrone — плагин Paper

Плагин показывает другим игрокам FPV-дрон, птицу или ванильного моба. Игрокам без мода не нужны моды и ресурспаки. Поддерживается Minecraft 26.3; сборка требует JDK 25.

## Установка

Соберите `gradlew.bat build` и положите JAR из `build/libs/` в `plugins/`. Удалите старый JAR плагина, сохранив папку `plugins/FpvDrone`: в ней лежат конфигурация, настройки скинов и кэш голов птиц. После запуска проверьте `plugins/FpvDrone/config.yml`. Если файл уже существовал, новые параметры можно добавить вручную по образцу `src/main/resources/config.yml`. Изменения применяются через `/drone reload`.

## Серверные ограничения

```yaml
max-range: 0              # 0: игрок выбирает 8–512 блоков; >0: фиксированное значение
stabilization:
  allowed: All             # All, Acro или Level
damage:
  durability: 0            # 0: выбор игрока; 4 и выше: неуничтожаемый дрон
  safe-contact: 0          # скорость безопасного касания, м/с
  propeller-break: 0       # порог поломки пропеллера, м/с
  motor-break: 0           # порог поломки луча/мотора, м/с
  frame-destroy: 0         # порог разрушения рамы, м/с
  liquids-destroy: client  # client, true или false
```

Числовое значение больше 0 фиксирует настройку у всех пилотов и блокирует соответствующий ползунок в моде. `client` оставляет игроку управление переключателем воды и лавы. При `max-range: 0` полёт также ограничен загруженными чанками.

## Скины и панель

`/flyskin` открывает меню птиц и ванильных мобов; `/flyskin list`, `/flyskin set <id> [вариант]` и `/flyskin reset` управляют выбором. `/flyskin admin` доступна операторам с `fpvdrone.admin`: ЛКМ включает или выключает скин, ПКМ меняет размер, нижние кнопки работают с разделом, стрелки переключают страницы, отдельная кнопка меняет разрешённую стабилизацию. Выключенные скины не показываются игрокам. Настройки панели сохраняются в `plugins/FpvDrone/skins-admin.yml`. При проблемах с окном используйте `/flyskin enable <id>`, `/flyskin disable <id>` и `/fpvdrone:flyskin diagnose`.

Птицы строятся из ванильных блоков и голов игроков. Для загрузки текстур голов используется MineSkin; настройка описана в [инструкции](ПТИЦЫ-СКИНЫ-ИНСТРУКЦИЯ.md). Ванильные мобы не переименовываются в Dinnerbone при повороте. На мирной сложности часть враждебных мобов может быть недоступна.

Команды `/drone help`, `/drone test` и `/drone reload` помогают проверить модель и применить настройки. Описание версий и разработческих ограничений находится в [корневом README](../README.md) и [AGENTS.md](../AGENTS.md).

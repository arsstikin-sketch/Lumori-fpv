# Трассы на время и назначения управления

## Создание трассы

Право `fpvdrone.race.admin` по умолчанию есть только у операторов. Администратор выполняет `/dronerace tool` и получает особый огненный стержень «Выделитель ворот дрона». ЛКМ по блоку отмечает первый угол, ПКМ по противоположному блоку — второй. Выделение включает оба блока целиком. Обычный предмет без метки плагина не работает.

1. `/dronerace create training` — создать трассу.
2. Выделить инструментом два угла первого триггера и выполнить `/dronerace gate training`.
3. Повторить выделение и ту же команду для каждого следующего триггера.

Тип выбирать не нужно: **первый созданный триггер — старт, последний — финиш, все между ними — промежуточные ворота**. Трасса готова после двух триггеров. Если добавить ещё один, прежний финиш станет промежуточным, а новый — финишем. `/dronerace undo training` удаляет последние ворота. Ворота должны находиться в одном мире, не пересекаться и быть не больше 64 блоков по каждой оси.

## Прохождение и рекорды

`/dronerace list` показывает кликабельный список трасс. Игрок выбирает одну через `/dronerace join training`, а `/dronerace leave` прекращает попытку. При пересечении стартового объёма запускается личный секундомер. До этого триггеры не подсвечиваются. После старта только **следующие обязательные ворота** показываются цветными частицами: промежуточные — жёлтым, финиш — красным. Старт считается зелёным триггером, но до его пересечения подсветка отключена. Пропуск ворот не засчитывается: проверяется только следующий ожидаемый триггер.

Проверяется весь отрезок движения дрона между отсчётами, поэтому быстрый пролёт через тонкие ворота засчитывается. Если за один отсчёт пройдены несколько ворот, они учитываются только в правильном порядке. На финише таймер останавливается. Каждый игрок видит своё время и номер ожидаемых ворот в action bar; другие игроки не видят его подсветку. Выход из трассы или потеря дрона отменяет текущую попытку.

`/dronerace records` открывает список трасс для выбора, `/dronerace records training` показывает рекордсменов и время. Лучшее время и ник на момент рекорда сохраняются в `plugins/FpvDrone/races.yml` по UUID игрока. При редактировании трассы старые рекорды переносятся в архив того же файла, чтобы не смешивать результаты разных вариантов.

## Назначение клавиш и кнопок

`O → Пульт → Клавиши…` открывает экран назначения действий и движения. Нажмите поле клавиатуры, затем клавишу; поле пульта — затем кнопку подключённого устройства. Esc отменяет захват, × очищает оба назначения строки. Страницы переключаются кнопкой снизу. Назначения кнопок сохраняются отдельно для каждого устройства в `config/fpvdrone-buttons.properties`. Для кнопок движения выбирайте устройство управления «WASD + мышь»; в режиме «Пульт» движение задаётся откалиброванными осями.

Назначение кнопки арма или выхода через этот экран заменяет соответствующий старый канал тумблера, чтобы одно нажатие не обрабатывалось дважды. Оси и калибровка остаются в окне «Настроить пульт».

Открытие игрового меню сохраняет арм и газ клавиатуры; кнопки действий в меню не вызывают случайного арма при закрытии. Полёт на сервере продолжается: открытое меню не ставит мир на паузу. Потеря фокуса окна и отключение устройства по-прежнему снимают арм.

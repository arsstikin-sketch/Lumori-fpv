# Плагин 0.7.x: птицы вместо дрона (без модов и без пака)

Архив текущей версии: FpvDrone-plugin-0.7.3-full.zip (исходники, README, ПТИЦЫ-СКИНЫ-ИНСТРУКЦИЯ.md). 0.7.0 протестирован на сервере: работает, скины голов грузятся.

- 35 существ (20 настоящих птиц + 15 выдуманных), 86 окрасок — из «Птички в клетке», вариант дизайна Б, серверный режим: ≤13 сущностей (головы игроков со скином + BlockDisplay).
- Только полёт: курс и крен как у дрона, нос по направлению полёта; газ → взмахи, мало газа → планирование, пике → крылья сложены, крен → голова держит горизонт, хвост веером; у земли лапы; дрон выключен → стоит со сложенными крыльями.
- Выбор в меню /flyskin (птицы первыми), хранится как раньше (`fpvdrone:flyskin`).
- Данные моделей: `src/main/resources/birds/birds.json`, картинки голов: `birds/skins/s0001…s0510.png`, отпечатки картинок: `birds/skins-index.json`.
- Скины голов: через MineSkin (ключ в `birds.mineskin-key`, 18/мин ≈ 30 мин). Результат — `plugins/FpvDrone/bird-heads.yml`, ключ в файле — отпечаток картинки (`h_<hash>`), поэтому при обновлении плагина головы не теряются.
- Свой скин игрока не меняется. Пока не загружено — части рисуются блоками.

## 0.7.1 (после первого теста)
- `own-drone: hide-while-flying | always-hide | always-show` (+ `own-drone-show-distance: 2.0`).
- Дрожь мелких птиц: `birds.max-flap-hz: 4`; пересоздание птиц во время загрузки — не чаще раза в 10 с.
- Плавность для зрителей: все части — пассажиры одной невидимой опоры; обновление каждый тик; `birds.smoothing: 10`, `birds.interpolation-ticks: 3`.

## 0.7.2 — панель `/flyskin admin`
- Окно-сундук (право `fpvdrone.admin`): ЛКМ — вкл/выкл, ПКМ/Shift+ПКМ — размер ±0.1, Shift+ЛКМ — +0.5, Q — по умолчанию; разделы Все / Птицы / Выдуманные / Мобы; страницы.
- Хранение: `plugins/FpvDrone/skins-admin.yml`.

## 0.7.3 — без ресурспаков, надёжная загрузка голов
- Полностью убраны ресурспаки (режим `pack`, веб-сервер пака, свои скины .bbmodel, примеры «ракета» и «стрекоза»). Скины — только птицы и настоящие мобы.
- Загрузка голов: стартует сама через 10 с после запуска (`birds.auto-upload: true`), продолжается после перезапусков; сторож раз в минуту, перезапуск при отсутствии ответа 3 мин; сначала первая окраска каждой птицы; неудачные — до 3 кругов, по 5 попыток; пауза по `rateLimit.next` из ответа MineSkin; сохранение каждые 10.
- Предзагрузка у игроков (`birds.preload-on-join: true`): через 5 с после входа игроку (только ему) показываются крошечные головы перед глазами пачками по 24 → клиент заранее скачивает текстуры. Профиль головы постоянный (UUID по отпечатку).
- Исправление растяжения и «застревания» частей: явная Transformation (сдвиг/поворот/размер) вместо матрицы.
- Установка с нуля: удалить старый jar и папку `plugins/FpvDrone`, поставить 0.7.3, вписать ключ, перезапустить.

## Подстройка
`birds.size-multiplier/min-size/max-size`, `head-size` (0.5), `head-yaw` (0/180), `head-offset-y`, `head-transform`, `smoothing`, `interpolation-ticks`, `max-flap-hz`, `auto-upload`, `preload-on-join`.

Не проверено вживую: предзагрузка голов, панель админа после переделки.

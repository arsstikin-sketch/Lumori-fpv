# FPV Drone — версия 0.4.1

| Папка | Что это | Куда ставить |
|---|---|---|
| `fpvdrone-mod` | мод **FPV Drone** (`fpvdrone-0.4.1.jar`) | у игроков **и** на Fabric-сервер |
| `fpvdrone-plugin` | плагин **FpvDrone** 0.3 | только Paper-сервер |

**Игрок:** `fabric-api`, `fpvdrone-0.4.1.jar` (+ по желанию `modmenu`).
**YACL больше не нужен** — можно удалить. FPV Freecam — тоже убрать.
**Fabric-сервер:** `fabric-api` + `fpvdrone-0.4.1.jar`.

## Что нового

### Настройки — свой экран, ползунки работают
Меню переписано на обычные виджеты Minecraft (без YACL): **ползунки тянутся мышью**, работают стрелками, всё применяется **сразу** — можно открыть настройки (**`O`**) прямо в полёте и крутить рейты/физику на ходу. Вкладки: Пульт · Рейты · Управление · Физика · Поломки · Вид · Экран и звук. У каждой вкладки есть «Сбросить вкладку». На «Рейты» видно итоговое макс. вращение в °/с.

**Новое в «Управление»:**
* **Интенсивность управления** — общий множитель скорости вращения (x0.3…x2).
* **Плавность управления** — сглаживание стиков (0 = мгновенно, больше = мягче).

### Звук моторов
Чем больше газ — тем громче и выше тон. Звук идёт из точки, где дрон (если смотришь от игрока — слышно издалека). Громкость: «Экран и звук → Громкость моторов».

### Вид «я / дрон» — клавиша `V`
* В полёте **`V`** — камера возвращается к игроку **в любой момент, хоть в воздухе**. Дрон дизармится и падает/лежит там, где был (другие его видят). Можно ходить.
* Ещё раз **`V`** (или `R`, или тумблер арма) — обратно в дрон, если он в зоне связи.
* **Если по игроку прошёл урон — дрон пропадает** (в любом виде).
* **`Backspace`** — убрать дрон совсем.

### Спавн
Дрон появляется **у ног** игрока (на полблока впереди). В режиме наблюдателя — у головы.

### Лежащий дрон больше не ползёт
Добавлено трение покоя: на земле дрон стоит на месте, даже армленный на холостом ходу.

### Калибровка — как в оригинальном моде
«Назначить» → подвигай стиком → мод нашёл ось и **2,5 секунды записывает её крайние положения** (води стиком до упора в обе стороны) → ось назначена **и откалибрована** одним действием. Для газа — сначала двигай **вверх**. Кнопка «Калибровка всех осей» тоже осталась.

### Настройка пульта по одной клавише — `K`
**`K`** в любой момент открывает экран настройки осей. Когда подключаешь новый пульт, вверху появляется подсказка «Пульт … подключён. K — настройка осей».

### Компас, расстояние
* Сверху **полоса компаса** (С/В/Ю/З по носу дрона) и метка **⌂** — где стоит игрок, с расстоянием в блоках. Если игрок сзади — метка у края со стрелкой.
* Справа: **«45 / 128 бл.»** — расстояние до игрока и предел дальности.
* В настройках дальность показана в блоках, рядом — какая дальность действует сейчас (своя или сервера).

### Подсветка и след (серверные опции)
* **Яркая модель:** все части светятся на полную (видно ночью), светодиоды больше — широкая полоса сзади и подсветка под носом цветом «Подсветка и след».
* **Обводка** цветом подсветки (видна сквозь стены) — выключена по умолчанию.
* **След:** полупрозрачная светящаяся линия за летящим дроном, плавно сужается и исчезает.

**Fabric-сервер** — `config/fpvdrone-server.properties`:
```
bright-model=true
glow-outline=false
trail-enabled=true
trail-seconds=3.0
trail-width=0.06
trail-visible-to-pilot=true
```
**Paper** — `plugins/FpvDrone/config.yml`: `bright-model`, `glow-outline`, `trail.enabled / seconds / width / visible-to-pilot`.

## Клавиши (Настройки → Управление → Клавиши → FPV Drone)
| Действие | По умолчанию |
|---|---|
| Запуск / арм / дизарм | R |
| Вид: я / дрон | V |
| Убрать дрон | Backspace |
| Новый дрон на старте | H |
| Настройка пульта (осей) | K |
| Настройки FPV Drone | O |

## Сборка
JDK 25: `./gradlew build` в `fpvdrone-mod` и `fpvdrone-plugin`. Ошибки — пришлите текст/`logs/latest.log`.

## Чек-лист
1. `O` → «Рейты»: ползунок RC Rate тянется мышью, «Макс. крен» меняется; в полёте вращение реально быстрее/медленнее.
2. «Управление → Плавность» на 100% — дрон заметно мягче.
3. Газ вверх/вниз — звук моторов меняет громкость и тон.
4. Взлёт с земли у ног. В воздухе `V` → камера у игрока, дрон падает; `V` → обратно.
5. Ударить игрока (или упасть) — дрон пропал.
6. Положить дрон на склон, подождать — не ползёт.
7. `K` → назначить крен: подвигать, поводить до упора 2,5 с → «откалибрована».
8. Ночью на сервере: дрон друга светится, за ним светящийся след.
9. Компас: метка ⌂ показывает, где игрок.
